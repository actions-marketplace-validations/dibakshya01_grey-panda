A note on responsible use

Grey Panda is a defensive security tool and a strong floor, not a ceiling. It helps you find and fix AI/agent/MCP risks — it does not certify compliance or replace a human review or red-team for high-stakes systems. Please read what it can & cannot do before relying on it.
